# 细节：裁图框怎么定，以及踩过的坑

## 环境

建议为每个翻译任务创建独立 Python 虚拟环境：

```powershell
python -m venv ".paper-edition-venv"
& ".paper-edition-venv/Scripts/python.exe" -m pip install -r requirements.txt
```

扫描版 PDF 的 OCR 流程需要额外安装：

```powershell
& ".paper-edition-venv/Scripts/python.exe" -m pip install -r requirements-ocr.txt
```

不建议直接装进系统 Python：PDF、图像和 OCR 依赖较多，独立环境更容易复现，也能避免与现有媒体处理工具发生版本冲突。

排版用到的中文字体取自 Windows 系统字体：`simsun.ttc`（正文宋体）、`simhei.ttf`（标题黑体）、`seguisym.ttf`（符号回退）。脚本里的字体路径是写死的 Windows 路径，换平台要改 `build_pdf.py` 顶部的 `SONG` / `HEI` / `SYM`。

## 怎么定裁图框

`crop_boxes.py` 里的矩形是 PDF 坐标（左上原点，单位 pt），只要**够大能包住目标**即可，脚本会收紧到墨迹边界；但**框小了会悄悄切掉内容**，所以每张图都会报告墨迹到框边的余量。

定位顺序：

1. 先跑提取，用 `dump_segments.py` 看每一段的 bbox。公式碎片、插图题注、算法行在原文里的位置一目了然。
2. 对插图：取图片区域上方到题注之间的整块（题目里的 `pXX-imgNN` 给出图片 bbox）。**矢量插图不一定被列为图片对象**，PBD 的图 2/4/5 就是纯矢量，只能靠题注位置往回推、并按周围文字的行范围框。
3. 对公式：按公式编号旁边的行范围框。原文里公式常与正文同一行（行内显示式），此时**宁可把引导句整行包进来**，也不要让框边切在行中间——切在行中间会在成品里留下一行半截英文。
4. 跑 `make_crops.py --report`，逐张核对 `crops.json` 里的 `text` 字段：框内文字应当正好是目标公式/题注。看到多出半句话就把框收一收，看到公式缺头少尾就把框放大。
5. 终端里报 `bleed into the crop` 的条目要人工判断：**1 个像素级邻接**通常是邻行的降部笔画，内容完整，可以放过；数量多或伴随 `no ink inside` 必须修框。
6. 引导句与公式在版面上交错时（PBD 的缩放因子 s、体积约束 (14)），把框收到题注之前的整行边界上，别把整段正文一起裁进来——正文已经在译文里了，裁进来会重复。

## 提取脚本的坑

- **判断"整行跨栏"不能拿页面最外缘做参照**。正文双栏、而页首整幅（标题 + 摘要）的页面，没有哪一行会同时顶到左右两侧的文字边界，于是整幅行会被从栏缝切开，摘要会变成左半句接右半句。现在按「宽度占比 / 左右是否均衡 / 是否居中 / 是否贴左边距」四条来判断。
- **小字号字形必须在切栏之前回挂到行**。正文里一个比正文小 1pt 的行内括号会在行中留下 80pt 空洞，后半行会被误判成右栏。现在先回挂再切栏。
- **栏宽取极值不行**。只要有一行稍长，所有齐行都会被判成"行末"，段落被拆成一行一段。现在取 10% / 90% 分位。
- **页眉页脚靠"小字号 + 跨页重复"两条同时成立才丢**，别用固定 y 区间去砍，否则会砍掉正文里的脚注。

## 排版脚本的坑

- **正文必须让 ReportLab 按中文逐字断行**（`ParagraphStyle(wordWrap="CJK")`）。否则一行里可用断点太少，两端对齐会把整行富余空白全摊到"中文与西文之间"那几个空格上，出现最大 11pt 的诡异间隔（正常半角空格只有 4.5pt）。这一项要用数值自查，别靠肉眼：抽取成品每一行的字符间距，统计 > 4pt 的个数。
- **宋体缺字形**：`∇`、真减号 `−`、上标字母、组合波浪号等宋体没有。排版脚本会逐字符比对字形表，缺的自动切到内嵌符号字体回退；但**连回退字体也缺的字符不要用**（组合波浪号 `r̃` 就是），要么换记法（PBD 3.5 节叉乘矩阵改用 `[r]×` 并在括号里注明原记法），要么放弃。
- **宽插图（宽于一个栏）会强制另起页顶栏**。连续多张必须合并到同一页，否则会留下一堆"只剩一张图的半空页"；`PLATE_LIMIT` 控制一页最多堆多高的图版。合并后如果某页还是空的，检查是不是把"图版之前的正文"排到图版之后去了。
- **中英混排的空格是半角 4.5pt**，不是排版错误。行尾的句号/顿号/右括号会略微探出右边界（标点悬挂），栏间距 19pt 足够容纳，也不算错误。
- 正文与标题之间不要随手加原文没有的小节号；图版页用不带编号的说明文字即可。

## 交付前的数值自查

这几项都能用脚本在几秒内跑完，比翻 PDF 可靠：

| 检查 | 做法 |
| --- | --- |
| 页边距 | 取每页所有词的 bbox，确认 x 在 [72, 526]、y 在页内；越界清单里应当只剩页眉页脚与标点悬挂 |
| 字符间距 | 抽取每行相邻字符的间隙，统计 > 4pt 的数量；应当只剩全角空格与标题里的空格 |
| 字形覆盖 | `build_pdf.py` 已内置：拿内嵌字体逐字符 `has_glyph` |
| 段落覆盖 | 把 `content/` 里所有 BLOCK 引用的段落 id 与 `segments.json` 比对，未被引用且是正文段落的就是漏译 |
| 交叉引用 | 正则扫译文里的"图 N""式 (N)""X.Y 节"，与实际的裁图清单、小节标题比对 |
| 可复现 | 删掉 `_work/` 后按三段流程重跑，页数、裁图数、字形覆盖应当完全一致 |
